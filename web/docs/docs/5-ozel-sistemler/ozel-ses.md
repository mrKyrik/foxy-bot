# Özel Ses Odaları

Kullanıcıların kendi ses odalarını yönetebilmesi için `f.oda-kurulum` komutu ile sistemi kurabilirsiniz.

Bu komut sayesinde otomatik olarak "Oda Oluştur" kanalı açılır ve giren kişiye özel yönetilebilir ses kanalı tahsis edilir.
